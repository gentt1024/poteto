# Changelog

## [v1.0.0](https://github.com/gentt1024/poteto/releases/tag/v1.0.0)

- First public package, named `poteto`, published by `gentt1024`.
- Nine standard animation states and sixteen look directions, 73 valid frames.
- Transparent V2 atlas, 1536 × 2288, with `spriteVersionNumber: 2`.
- Chief work loop: thought, compact instruction, delayed helper response and tray inspection.
- Preserves the approved sprite artwork and previews without additional redraws or animation changes.
- Known limits: brisk stepped work animation; some older-state color/style differences; reduced fine-detail readability at small sizes.
- Reference rights and likeness permissions remain unconfirmed. Official schema compatibility and desktop import testing remain unverified.
